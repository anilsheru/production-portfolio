# frameandflavour

A responsive, single-page photography and videography production-agency portfolio.

## Files

- `index.html` — page content and structure
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile navigation behavior

The project is deliberately dependency-free: open `index.html` in any browser to preview it, or publish the repository with GitHub Pages.

## Before publishing

Replace the fictional projects, testimonial, contact email, and CSS artwork with frameandflavour's own work and real contact details.
